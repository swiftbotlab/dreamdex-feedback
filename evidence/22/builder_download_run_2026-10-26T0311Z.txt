1 · Your config (.env)

Download
# DreamDEX bot config — generated by the Bot Builder
# Add your own funded key below. Never share it, never commit this file.
NETWORK=hideki
DRY_RUN=true
STRATEGY=perp-starter
PRIVATE_KEY=0x...

PERP_SYMBOL=BTC-PERP
PERP_SIDE=long
PERP_NOTIONAL_USDSO=50
PERP_LEVERAGE=2
PERP_TAKE_PROFIT_PCT=2
PERP_STOP_LOSS_PCT=1
PERP_TICK_MS=10000
PERP_FLATTEN_ON_EXIT=false
Copy

Replace the 0x... placeholder with your own key, and it must start with 0x - like PRIVATE_KEY=0xabc123…. MetaMask exports the key without the 0x, so add it to the front yourself. How to export your key → This site never sees your key. Use a dedicated bot wallet.

Before the first run · fund the bot key
With no DreamDEX account wallet address set, the bot trades its own key's perps account. Fill it in on the Tune step to trade your app account through a linked bot instead.
Send the key Hideki testnet STT for gas. A Perp Starter bracket also locks 0.30 STT while it is armed, returned when it is cancelled.
Deposit USDso into the key's MarginBank. A perp order locks margin from the bank, not the wallet, so an empty bank fails every order.

npm run perp:doctor shows the gas, the wallet USDso and the margin in one read, and sends nothing.

2 · Run it

Option A · 24/7 on Railway (easiest)

Keep it running around the clock without your laptop on. No server setup: deploy the kit's Railway template, paste your config, and add your key. Railway's free credit covers light use; a bot running 24/7 may cost a few dollars after that.

Deploy on Railway
Click the Deploy on Railway button above.
In the Railway service, open Variables → RAW Editor and paste your .env block from above.
On the PRIVATE_KEY=0x... line, replace 0x... with your own key (keep the 0x prefix), then deploy.

The service may show a "crashed" status until you paste your config. That's expected; it starts as soon as your variables are set.

Option B · on your machine (free)
git clone https://github.com/somnia-chain/dreamdex-bot-kit
cd dreamdex-bot-kit
npm install
# save the .env above into this folder, then:
npm run perp:doctor
npm run dev -w perp-starter
