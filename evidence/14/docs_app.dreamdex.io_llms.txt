# dreamDEX Documentation

> dreamDEX is a fully on-chain CLOB DEX on the Somnia network: zero-fee spot trading, event contracts, and a yield-bearing order book. User guides plus developer docs for the smart contracts, HTTP API, WebSocket API, and event-contract SDK integration.
